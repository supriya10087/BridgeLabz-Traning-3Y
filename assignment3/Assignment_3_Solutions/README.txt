How to run:
1. Extract this ZIP.
2. Open the Assignment_3_Solutions folder in VS Code.
3. Open a terminal in the folder.
4. Run a file with: node Q1_Dynamic_Data_Parser.js
   Replace the filename for each question.

Debugging tasks:
- Set breakpoints by clicking beside a line number.
- Press F5 and choose a Node.js debugger if prompted.
- Add relevant variables in the WATCH panel and inspect CALL STACK.

Notes:
