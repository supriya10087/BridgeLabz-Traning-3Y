# JavaScript Assignment 4 — Solutions

This folder contains beginner-friendly solutions for all 9 questions from the assignment.

## How to run
- **Console-based questions (Q1, Q3, Q6, Q9):** Open a terminal in this folder and run `node Q1_Ecommerce_Product_Manager.js` (replace the filename as needed).
- **Browser questions (Q2, Q4, Q5, Q7, Q8):** Open the matching `.html` file in a browser. Each HTML file loads its corresponding JavaScript file.
- No frameworks or external libraries are used.

Each question has a separate JavaScript file. HTML files are included only where the assignment requires forms or DOM updates.
