Responsive Design Principles

Fluid Layouts

Layouts use flexible widths so content can adapt to available space.

width: 100%;
max-width: 1200px;

Flexible Media

Images and other media should resize within their containers.

img {
  max-width: 100%;
  height: auto;
}

Breakpoints

Media queries adjust the layout when the screen reaches a chosen width.

@media (max-width: 600px) {
  .box { width: 100%; }
}
