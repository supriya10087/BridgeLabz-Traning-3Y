Responsive CSS Cheat Sheet

Filters

Change an image's appearance.

filter: grayscale(100%);

Media Queries

Apply styles at selected screen widths.

@media (max-width: 700px) { }

Responsive Design

Build layouts that adapt to devices.

width: 100%; max-width: 1100px;

Typography

Scale text with relative units.

font-size: clamp(1rem, 2vw, 1.5rem);
